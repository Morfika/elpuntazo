# El Puntazo - Expendio de Carnes

## Información del Proyecto

**Sitio Web**: ec.elpuntazo

## Descripción

Sistema de gestión integral para El Puntazo, expendio de carnes en Chipaque. Incluye:
- Sitio web informativo con secciones educativas sobre cortes de carne
- Sistema administrativo para gestión de ventas, gastos y flujo de caja
- Gestión de múltiples sedes
- Reportes financieros y contables

## Tecnologías Utilizadas

Este proyecto está construido con:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Base de datos y autenticación)
- Framer Motion (Animaciones)

## Cómo Editar el Código

### Requisitos Previos

Tener Node.js & npm instalado - [instalar con nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Pasos para Desarrollo Local

```sh
# Paso 1: Clonar el repositorio
git clone <YOUR_GIT_URL>

# Paso 2: Navegar al directorio del proyecto
cd elpuntazo

# Paso 3: Instalar las dependencias necesarias
npm i

# Paso 4: Configurar variables de entorno
# Copiar .env.example a .env y configurar las credenciales de Supabase

# Paso 5: Iniciar el servidor de desarrollo
npm run dev
```

### Editar Directamente en GitHub

- Navegar a los archivos deseados
- Hacer clic en el botón "Edit" (ícono de lápiz) en la parte superior derecha
- Realizar los cambios y hacer commit

### Usar GitHub Codespaces

- Navegar a la página principal del repositorio
- Hacer clic en el botón "Code" (botón verde) cerca de la parte superior derecha
- Seleccionar la pestaña "Codespaces"
- Hacer clic en "New codespace" para lanzar un nuevo entorno Codespace
- Editar archivos directamente dentro del Codespace y hacer commit y push de los cambios

## Estructura del Proyecto

- `/src/components` - Componentes reutilizables de React
- `/src/pages` - Páginas principales de la aplicación
- `/src/hooks` - Custom hooks de React
- `/src/contexts` - Contextos de React (Auth, etc.)
- `/src/lib` - Utilidades y configuración (Supabase, etc.)
- `/public` - Archivos estáticos (imágenes, logos, etc.)
